# Практичне завдання 4. Середня маса правильна. Чому покупці скаржаться?

**Мета:** побачити, як загальне середнє приховує різницю між групами, та визначити, які відомості потрібні для пояснення результатів.

**Орієнтовний час:** 15 хвилин. Потрібен Excel або інша електронна таблиця.

## Перед дослідженням: переклад

- [ ] Знайдіть англомовну довідку до функцій `AVERAGE` та `STDEV.S` у використаному табличному редакторі. Перекладіть короткий фрагмент про призначення кожної функції та поясніть терміни `mean`, `sample standard deviation`, `sample size`. Можна використати ШІ або перекладач, але додайте посилання на довідку й звірте оригінал.

## Ситуація

Кав'ярня продає пакети з цільовою масою **250 г**. Власник стверджує: «Середня маса рівно 250 г — фасування працює правильно».

Нижче наведено **синтетичні навчальні покази**, а не результати перевірки реального виробника.

| Спостереження | Зміна A, г | Зміна B, г |
| ---: | ---: | ---: |
| 1 | 247 | 251 |
| 2 | 248 | 252 |
| 3 | 249 | 253 |
| 4 | 248 | 252 |
| 5 | 248 | 252 |

## Етап 1. Перевірити аргумент власника

1. Перенесіть дані до двох стовпців таблиці.
2. Обчисліть загальне середнє десяти показів.
3. Для кожної зміни окремо обчисліть кількість спостережень, середнє та вибіркове стандартне відхилення. Використайте `AVERAGE` та `STDEV.S` або їхні відповідники.
4. Побудуйте точкову діаграму: по горизонталі номер спостереження, по вертикалі маса в грамах; дві зміни позначте різними кольорами. Додайте горизонтальний орієнтир 250 г.
5. Запишіть попередній висновок. Складіть перелік трьох відомостей, які запросили б до пояснення причини розбіжності.

| Серія | n | Середнє, г | Вибіркове s, г |
| --- | ---: | ---: | ---: |
| A | | | |
| B | | | |

Числові результати не змінюйте під очікуваний висновок.

## Етап 2. Відкрити історію вимірювань

**Спочатку збережіть висновок першого етапу.** Викладач призначає одну картку кожній команді; за самостійної роботи розгляньте обидві.

<details>
<summary>Картка A — ті самі пакети, різні ваги</summary>

Обидві зміни зважували **ті самі п'ять контрольних пакетів**, але користувалися **різними вагами**. Рядки таблиці відповідають тим самим пакетам. Маси пакетів між перевірками приймаємо незмінними, інші умови — порівнянними.

</details>

<details>
<summary>Картка Б — різні пакети, ті самі ваги</summary>

Обидві зміни зважували **різні пакети**, але користувалися **тими самими стабільними контрольними вагами**. Умови зважування приймаємо порівнянними. Причину можливої різниці у фасуванні не задано.

</details>

Картки описують **альтернативні ситуації**, а не дві послідовні події.

Для своєї картки:

1. Поясніть, яку гіпотезу тепер підтримують дані.
2. Назвіть висновок, який усе ще не можна зробити.
3. Запропонуйте наступну перевірку: що, чим і в яких умовах потрібно виміряти.
4. Порівняйте рішення з командою, яка отримала іншу картку.

Для картки A додатково обчисліть попарні різниці B − A. Для картки Б поясніть, чому сама наявність рядків із однаковими номерами не робить різні пакети парними вимірюваннями одного об'єкта.

## Етап 3. Чи допоможе більше даних?

Уявіть, що кожна зміна збере ще сто показів із приблизно такими самими груповими середніми та внутрішнім розсіюванням.

Обговоріть, що можна буде оцінити краще, а яке питання про причину розбіжності залишиться. Не копіюйте наявні рядки як «нові вимірювання»: дублювання записів не додає незалежної інформації.

## Питання до результатів

1. Чому правильне загальне середнє не підтверджує правильності кожної групи?
2. Чи показує мале внутрішнє s відсутність зміщення між групами?
3. За карткою A чи відомо, які саме ваги зміщені, якщо опорної маси немає?
4. За карткою Б чи достатньо цих даних, щоб встановити причину зміни фасування?
5. Яку інформацію потрібно зберігати разом із числами, щоб інша людина могла обґрунтовано порівняти серії?

**Обмеження:** дані спеціально підібрані для наочного ефекту. Цільові 250 г не є відомою істинною масою кожного пакета. Нормативні вимоги до фасованої продукції тут не оцінюємо. Загальне середнє описує ці десять показів, але його зміст залежить від об'єктів, приладів та умов.
